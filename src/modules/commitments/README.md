# ماژول تعهدنامه و امضا (Commitments Module)

این ماژول مدیریت قالب‌های تعهدنامه، جای‌گذاری متغیرها سمت سرور (`{{variable_key}}`)، بررسی سلامت و یکتایی نسخه فعال، ثبت پذیرش اقرار الکترونیک راننده و ذخیره امضای ترسیمی را بر عهده دارد.

## مرزهای ماژول
- جداول: `commitment_versions`, `commitment_acceptances`.
- نسخه تعهدنامه تغییرناپذیر است؛ تغییر متن = ثبت نسخه جدید با وضعیت DRAFT یا ACTIVE.
- حالت‌های اعمال: `COMMITMENT_ENFORCEMENT` (OFF/SHADOW/ENFORCED).
