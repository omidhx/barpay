# ماژول گزارش‌ها (Reports Module)

این ماژول مسئول تولید گزارش‌های آماری، مالی و عملیاتی سامانه (از جمله گزارش عملکرد روزانه، تسویه حساب‌ها، مبالغ افزوده، پرداخت‌های درگاهی و نرخ پذیرش تعهدنامه‌ها) بر اساس فازهای مشتق و داده‌های سازمان است.

## مرزهای ماژول
- کوئری‌ها بر اساس `organization_id` فیلتر شده و خروجی‌ها در فرمت‌های JSON و خروجی اکسل/CSV قابل تولید هستند.
- عملیات محاسباتی سنگین در صورت نیاز به پس‌زمینه (graphile-worker) سپرده می‌شود.
