# ماژول ورود اطلاعات اکسل (Imports Module)

این ماژول مسئول ورود فایل‌های اکسل/CSV بارنامه‌ها، استخراج و نگاشت ستون‌ها بر مبنای تنظیمات سازمان، اعتبارسنجی ۱۱ گامی، محاسبه اتمیک مبالغ و ساخت بارنامه‌ها است.

## مرزهای ماژول
- جداول: `import_batches`, `import_rows`, `excel_column_mappings`.
- ناورداها: ورود مجدد فایل بر اساس `file_hash` بررسی و جلوگیری می‌شود.
- ردیف‌های صفر/صفر (مبلغ پرداختی صفر و وزن صفر) پیش از ورود لغو تلقی شده و به عنوان `SKIPPED_PREVIOUSLY_CANCELLED` ثبت می‌شوند بدون ساخت رکورد عملیاتی.
