# ماژول اسناد و PDF (Documents Module)

این ماژول مسئول بارگذاری گروهی اسناد بارنامه، استخراج شماره بارنامه از نام فایل، تطبیق خودکار ۱:۱، اتصال دستی و تعویض کنترل‌شده فایل‌های PDF بارنامه است.

## مرزهای ماژول
- جدول اصلی: `documents`
- ناورداها: حداکثر یک PDF فعال به‌ازای هر بارنامه (ایندکس یکتای جزئی).
- دسترسی به فایل‌ها: در ذخیره‌ساز خصوصی (Private Storage)، دسترسی تنها از طریق اندپوینت محافظت‌شدهٔ `canRelease`.
