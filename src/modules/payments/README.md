# ماژول پرداخت‌ها و درگاه‌ها (Payments Module)

این ماژول مسئول ثبت، پردازش و بررسی پرداخت‌های رانندگان (درگاهی و دستی)، کارت‌های واریز سازمان، آداپتر یکپارچهٔ درگاه‌های پرداخت، و تراکنش‌های بازگشت وجه است.

## مرزهای ماژول
- جداول: `payments`, `payment_reviews`, `payment_refunds`, `payment_gateways`, `gateway_transactions`, `bank_cards`.
- تصمیم ۲۰ نسخه ۲.۵: شش ارائه‌دهنده پشت آداپتر واحد `PaymentProvider` (سامان، ملت، پاسارگاد، سداد، زرین‌پال، زیبال).
- تصمیم ۲۱ نسخه ۲.۵: کارت‌های واریز گرافیکی با اعتبارسنجی Luhn و MOD-97.
- ناورداها:
  - وریفای فقط server-to-server است و پارامترهای callback اعتماد نمی‌شوند.
  - حداکثر یک درگاه فعال به‌ازای هر سازمان (ایندکس یکتای جزئی).
  - حداکثر یک تلاش باز درگاه به‌ازای هر بارنامه.
  - ثبت پرداخت دستی نیاز به بررسی و تایید انسانی دارد؛ پرداخت درگاهی تنها با وریفای موفق خودکار تأیید می‌شود.
  - مبالغ همگی BIGINT ریال هستند؛ تبدیل به تومان تنها داخل آداپتر زرین‌پال مجاز است.
