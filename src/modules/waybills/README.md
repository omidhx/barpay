# ماژول بارنامه‌ها (Waybills Module)

این ماژول هستهٔ مدیریت بارنامه‌ها، نگهداری رکورد اصلی بارنامه، تغییرناپذیری هویت بارنامه (`waybill_number` و `waybill_year`)، تاریخچهٔ مبالغ، ارتباط با راننده و کنترل وضعیت‌های ۵ گانه بارنامه است.

## مرزهای ماژول
- جداول: `waybills`, `waybill_amounts`, `drivers`, `driver_access_links`, `driver_sessions`.
- پنج محور وضعیت بارنامه و فازهای مشتق در این ماژول هدایت می‌شوند.
- مبالغ منحصراً از جدول `waybill_amounts` خوانده می‌شوند.
- اصلاح مبلغ پس از پرداخت تنها با ثبت رکورد مبالغ جدید و ثبت دلیل (CHECK constraint) صورت می‌گیرد.
