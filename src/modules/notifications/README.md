# ماژول اعلان‌ها و پیامک (Notifications Module)

این ماژول مسئول مدیریت مرکز اعلان‌های داخلی پنل و ارسال پیامک‌های OTP و اطلاع‌رسانی به رانندگان با سوئیچ خودکار بین فراز اس‌ام‌اس و ملی‌پیامک و الگوی مدارشکن (Circuit Breaker) است.

## مرزهای ماژول
- جداول: `notifications`, `notification_jobs`.
- صف: ارسال پیامک از طریق صف graphile-worker انجام می‌شود با SLA کمتر از ۳۰ ثانیه (p95).
- محدودیت‌ها: سقف روزانه ۲٬۰۰۰ پیامک برای سازمان، لاگ‌نشدن شماره‌های راننده به‌صورت خام (`0912***1234`).
