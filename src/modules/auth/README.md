# ماژول احراز هویت و دسترسی (Auth Module)

این ماژول مسئول احراز هویت کاربران پنل (موبایل و رمز عبور)، کنترل دسترسی مبتنی بر نقش و مجوزها (RBAC + Permissions)، مدیریت نشست‌های DB-backed و همچنین اعتبارسنجی لینک و OTP رانندگان است.

## مرزهای ماژول
- جداول اصلی: `users`, `user_permissions`, `driver_access_links`, `driver_sessions`, `otp_challenges`.
- رانندگان در جدول `users` ثبت نمی‌شوند؛ احراز آن‌ها بر پایه لینک کوتاه‌عمر و OTP پیامکی است.
