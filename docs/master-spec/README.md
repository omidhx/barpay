فایل [barnameh-pay-master-doc-2.5.md](barnameh-pay-master-doc-2.5.md) (۳۶۹۳ خط) **منبع سیاست و تصمیم** این پروژه است:

- حاصل ادغام سه سند طراحی مستقل + پاسخ‌های قطعی ۱۸ سوال کسب‌وکار (فصل ۴.۵)
- چهار دور اصلاح راستی‌آزمایی‌شدهٔ نقد ۶ مدل AI خارجی (V4 تا V7)
- سه تصمیم جدید صاحب کسب‌وکار در نسخهٔ ۲.۵ (فصل ۴.۶): تعهدنامه پیش از پرداخت،
  درگاه پرداخت در MVP، ماژول کارت‌های واریز گرافیکی
- پیوست‌ها: الف (گزارش اعتبارسنجی منابع) · ب (تصمیم‌های ردشده — برای جلوگیری از
  بازگشتن پیشنهادهای ردشده) · ج (مشخصات یکپارچه‌سازی ۶ درگاه)

## چه استفاده‌ای از آن می‌شود؟

| زمان | استفاده |
|---|---|
| شروع هر قابلیت جدید | مرجع «چرا» هر تصمیم — وقتی فایل اجرایی کوتاه است، دلیل کامل اینجا است |
| اختلاف در تفسیر | چهار فایل اجرایی مقدم‌اند؛ اما ریشه‌یابی و اصلاح باید به این سند برگردد (issue ثبت شود) |
| مرور پیشنهادهای جدید AI/تیم | ابتدا پیوست ب (تصمیم‌های ردشده با دلیل) چک شود تا کار تکراری نشود |
| آپدیت مستندات | تغییر سیاست = ویرایش سند مادر + همگام‌سازی فایل اجرایی مربوطه در همان PR |
